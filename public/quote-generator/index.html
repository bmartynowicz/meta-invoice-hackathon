FOR AI AGENTS Your agent drafts the quote, you approve it. No API key needed

Any software agent can pre-fill this quote generator by opening a link with parameters in the URL fragment (after #). The fragment is processed by the browser and never sent to the server or included in referrers. No signup, no API key, no backend. The quote builds itself client-side, ready to review and download as PDF. Full guide for agents → Example:

https://monkeetools.pages.dev/quote-generator/#v=1&to=Acme%20Corp&item=Brand%20refresh|1|2400&item=Extra%20concepts|2|300&currency=USD&tax=0&valid=2026-10-15
  • to / from: client and business names
  • bc / cc: business and client contact details
  • item: repeatable; format Description|qty|rate (up to 12 items); optional 4th segment for longer detail text: Name|qty|rate|Longer details
  • currency: USD, EUR, GBP, CAD, AUD, JPY
  • tax / discount: numbers; discount is a percent unless disctype=amt (dollar amount)
  • quote, date, valid: quote number, issue date and valid-until date (YYYY-MM-DD)
  • notes / terms: free text
  • accent: 6-digit hex brand color
  • tpl: quote design, classic, minimal, or modern
